The problem

申請一項給付，民眾要面對什麼？

政好的回答： 政好先理解生活事件，再從服務目錄找出可能適用的政府方案。
15 日幼兒送托後若未及時完成申請，補助起算日可能順延——政府服務的難，不只是找不到，而是錯過就影響權益。

Solution architecture

民眾只需要面對 Agent

1. 民眾 → Agent說明需求、授權必要資料、最後確認送件。
2. Agent → 信任來源向數位憑證皮夾驗證資格，經同意向 MyData 調閱資料。
3. Agent → 政府機關通過政策閘門後送件，並為每個案件保存完整時間線。
不是「打通所有資料庫」：個資利用必須與特定目的具有正當合理關聯；政好讓民眾逐案決定用途與資料範圍。

Trust by design

信任不是一句承諾，而是四個系統規則

01

資料最小化

只取本次服務必要的資格結果，不把完整個資集中交給 Agent。

02

授權有邊界

代查、建草稿、正式送件是不同動作，不能用同一層授權一路到底。

03

規則決策

AI 負責理解與解釋；資格判定與送件條件由確定性規則控制。

04

疑則不放行

憑證失效、資料不足或本人未確認就停止，不讓 Agent 自行猜測。
